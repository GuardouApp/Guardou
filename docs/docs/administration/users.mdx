# Users and Quotas

Manage users under **Admin → Users**.

## User types

| Type    | Permissions                                       |
| ------- | ------------------------------------------------- |
| `user`  | All file operations in the own files.             |
| `admin` | Same as `user`, plus the admin panel.             |

Each user sees only the own files and the files that other users share with them.

The first account that you create is an `admin`. Users from [single sign-on](./oidc) get the `user` type.

## Rules

- You cannot delete your own user.
- The last `admin` cannot become a `user`.

:::danger

Delete user removes the user and all files of the user. You cannot undo this action.

:::

## Quotas

Set **Quota (GB)** in the user dialog. Leave it empty for no limit.
