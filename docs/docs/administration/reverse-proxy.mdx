# Reverse Proxy

Guardou listens on HTTP port `2286`. Use a reverse proxy for HTTPS.

## Requirements

- Set **External URL** under **Admin → Settings → Server**, or `EXTERNAL_URL`.
- Permit request bodies at least as large as the upload chunk size (`UPLOAD_CHUNK_SIZE_MB`, default 64 MB).
